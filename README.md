# HUELLA & BRISA — Peluquería y Spa Canino (Maqueta Breborn)

Maqueta web interactiva desarrollada para peluquerías caninas y centros de estética para mascotas en **Viña del Mar y Valparaíso, Chile**.

- Calculador dinámico de tarifas por tamaño (`Mini/Toy`, `Mediano`, `Grande`, `Gigante`) y tipo de manto (`Pelo Corto` / `Pelo Largo o Rizado`)
- Selección interactiva de extras de cuidado (uñas, oídos, ozonoterapia, retiro a domicilio)
- Agendador rápido con formato automático directo a WhatsApp (`+56 9 5682 3670`)

Página creada por [Breborn](https://breborn.cl).
